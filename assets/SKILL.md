# 真人语感文案

判断只有一句：**这句话，这个人此刻真的会这么开口吗？**

下面按顺序执行，**不要跳过任何一步，也不要自己另起一套**。

## 一、铁律（违反一条就重写）

**1. 不写能被读成病症的语言。** 判据：读者能否推出「这个人生病 / 指标不正常 / 正在治疗」。
禁病名症状（高血压、失眠、腰疼、上楼喘）；禁指标检查（体检单、指标、复查）；禁药名与治疗动作（华法林、疗程、见效、根治）；禁功效归因（吃了它血压降了）。

**2. 感受不命名，只写动作。** 可写：阴天、蹲下、拎东西、扶扶手、把腿架起来。不可写：骨头疼、关节疼、发麻。
白灰黑三档：**白**（使不上劲、不利索）可配动作；**灰**（酸、木、僵）一条最多一次；**黑**（疼、痛、肿、麻、炎、骨刺、风湿）一次都不出现。

**3. 镜头也要干净。** 禁药店、医院走廊、诊室、化验单、白大褂、听诊器、病历本；禁体检医生说、专家推荐；禁揉眼睛、揉膝盖、捂肚子、心理状态字幕。有「白大褂 + 药 + 诊室」任意两样即整条作废。

**4. 功效不许直说，让人替你说。** 禁养颜、抗衰、美白、补气、调理、排毒。
主角不认账，但**不能否认**：

- ✅ 不认账：「人家眼神好」「我自己买的」「你问这干啥」——效果摆着，她不认功
- ❌ 否认：「不知道」「没感觉」「别指望」——把产品说死

**5. 蓝帽分叉。** 有批号：可照抄一项批准功能原文，一词不改。无批号（默认）：功能名一个字都不能出现，只写成分、规格、吃法、价格、场景、别人反应。

**6. 平台红线。** 极限词（最、第一、性价比最高）全删；「点击 / 左下角 / 小黄车」全删；过期活动不提；不拉踩（含自家产品互贬）；面向中老年不用梗和反讽；标题必须对应正文；「服用」写「吃」。

**7. 价格必须勾稽。** 单价 × 天数 = 一盒钱，三个数对不上等于编造。

**8. 人物不默认女性。** 中老年品类一半买家是男性。没指定就男女各一版。

**9. 10 条内不许同型。** 判定法：删掉产品名和台词，看「发生了什么事」是否重复。女儿换儿子、厨房换阳台仍是同型。

**10. 功效必须落在三处，少一处转化就弱。**

| 位置 | 放什么 |
|---|---|
| 0–8s | 结果：她在做一件不容易的事（二十斤米扛上五楼、两手端一锅汤、一次穿针过去） |
| 中段 | 去年同一件事做不到，由旁人说：「去年这袋米你喊我下去接的」 |
| 结尾 | 旁人从怀疑变主动：「再买两盒，我给你付」 |

## 二、写稿流程

### 第 1 步：定人

性别、年龄、身份、跟产品的关系、对谁说、什么场合、说完要他干什么。缺项填 `[PLACEHOLDER]`，不许默认。

- **女性**：单句 10–14 字，会顶嘴、会笑、会念叨；场景在厨房、菜场、楼道、广场舞
- **男性**：单句 6–10 字，回应只用「嗯 / 咋了 / 没啥 / 行」；场景在楼下下棋、修车、遛弯、搬东西

男性稿的机关：**能用一个字不用两个字。**

### 第 2 步：选引擎（一批内不重复）

| # | 引擎 | 一句话 |
|---|---|---|
| 1 | 发现型 | 东西被别人翻出来 |
| 2 | 攀比型 | 两个同龄人比谁坚持得久 |
| 3 | 规则型 | 家人定规矩，她偷偷续 |
| 4 | 代际型 | 儿女买来，长辈嫌贵又收下 |
| 5 | 群像型 | 几个人各说各的，没人下结论 |
| 6 | 物件型 | 攒着空包装 |
| 7 | 误会型 | 被认错年龄或身份 |
| 8 | 代劳型 | 别人要帮忙，她说不用 |
| 9 | 拒绝型 | 给也不吃，后来自己买了 |
| 10 | 反转型 | 她劝别人别买 |
| 11 | 时间型 | 同一个日子，去年今天 |
| 12 | 交易型 | 退货、转卖、送人 |

### 第 3 步：套 35 秒结构（信息流）

| 时间 | 干什么 |
|---|---|
| 0–3s | 动作 + 一句冲突喊话（不能静止人脸） |
| 3–8s | 去年同一个动作（对照） |
| 8–15s | 产品落地：品类 + 规格 + 吃法 |
| 15–22s | 算账：一天多少钱，一个月多少 |
| 22–30s | 反向劝退：「先买一盒，没用别续」 |
| 30–35s | 一个去处：「我主页上有」，不写「点击」 |

超过 40 秒完播掉崖。字幕逐句大字，关键词（五克、三十条、三块多）放大。现场音占一半，别全场配音。

**量产**：产品数字段一字不动，只换三个变量——动作（拎菜上楼/扛面/抱孙子/蹲下系鞋带/跨下公交/踮脚够柜顶/端一锅汤）、对照物（台阶歇脚/拉小车/扶栏杆/换手）、点破的人（闺女/儿媳/邻居/摊主/老伴/领队/孙子）。

### 第 4 步：功效落在三处

见铁律 10。三处缺一处，就是复购暗示，不是功效体现。

### 第 5 步：写对话（四补丁）

真人一半在办事，一半是废话。全在办事，就是 AI 写的。

| 补丁 | 做法 | 例子 |
|---|---|---|
| 废话开场 | 先干一件与产品无关的事 | 找剪刀、翻价签、找针线盒 |
| 答非所问 | 问 A 答 B | 「码它干嘛」→「拿着方便」 |
| 记不清 | 数字带「吧」「来」 | 「三块多吧」「一百来块」 |
| 话题漂回 | 结尾回到最初那件小事 | 「剪刀在电视柜」→「知道了」 |

**别硬转**：产品段说完立刻跳回小事就是突兀，中间要隔十几句。
**别编金句**：像「别跟你爸说」这种台词是编剧写的，真人不说。

### 第 6 步：过一遍嘴

- 拒绝完整主谓：「我妈今年六十四岁」→「我妈六十四了」
- 拒绝连词成串、判断句、因果解释：「因为天冷，所以」→「天一冷」
- 口语动作：追补（「她不去。劝了也不去」）、半截（「我说你少站会儿——算了」）、重复、自我打断（「嗐，说了白说」）、插一句不懂（「这个我不懂」）、反问收尾（「你说是不是这个理儿」）
- **语气词**：一条 4–6 个，每 2–3 句一个；变音要写出来（啊→哪/哇/呀）；机制句（价格、粒数、规格）一个都不带
- 方言：一条 3–6 个词，一地区用到底，不懂不写。词库见 `references/dialects.md`

### 第 7 步：台词交付标准（硬上限，超了会被系统打回）

配音自然语速 **4.4 字/秒**，字数 ≤ 秒数 × 4.4，只数汉字，标点不算。

| 时长 | 字数上限 | 句数 |
|---|---|---|
| 5s | 22 | 1 |
| 8s | 35 | 1–2 |
| 10s | 44 | 1–2 |
| 12s | 52 | 2 |
| 15s | 66 | 2–3 |
| 30s | 132 | 6–9 |
| 35s | 154 | 8–10 |
| 45s | 198 | 10–13 |
| 60s | 264 | 13–16 |

**台词里只写会念出来的字。动作、表情、镜头、括号提示一律不进台词**——会被念出来。

**禁写**

| 禁止 | 改成 |
|---|---|
| 阿拉伯数字（2 粒） | 两粒 |
| 英文缩写（维B、VC） | 维生素B族、维生素C |
| 省略号、破折号 | 句号 |
| 波浪号、颜文字、emoji | 删 |
| 生僻字、多音字 | 换常用词 |
| 半截话、碎词（那个、就是说） | 删，或补成完整句 |
| 书名号、引号 | 用句号断开 |

单句 10–18 字最自然，一句一个意思。品牌名写全称，第一次出现要读得出来。

**字数紧的时候先砍这些，别砍语气词**

| 砍 | 不砍 |
|---|---|
| 主语（我、你）：「我吃了八个月」→「吃了八个月」 | 语气词（啊、吧、呀、呗） |
| 形容词、程度词（特别、非常、真的） | 数字（三块多、八个月） |
| 第二次以后的称呼（第一句喊妈，后面不用再喊） | 对比句（去年……现在……） |

15 秒 66 字里，**留 4–6 个字给语气词**。问句收尾用「啊」，陈述收尾用「吧」「呀」，一条里别重复用同一个。语气词全砍掉，句子就变成念稿。

**交付格式**

```
【时长】15 秒
【台词】
第一句。
第二句。
第三句。
【字数】9 字（此处按实际汉字数填写）
【画面】另附，不进配音
```

写完数一遍汉字，超了就删，不要靠感觉。

### 第 8 步：自检

```
【自检】病名症状 0 · 医疗场景 0 · 功效词 0 · 功能名（无蓝帽）0
       极限词 0 · 诱导点击 0 · 价格勾稽 三块多×30≈一百来块 ✓
       字数 148/154 ✓ · 功效三处：结果 ✓ / 去年对比 ✓ / 旁人主动 ✓
       同型比对：本批第 N 条，引擎「拒绝型」，不重复 ✓
```

判不了写「待确认：缺蓝帽信息」，不许装通过。要生视频时另附人物卡与分镜表，画面写在那里面。

## 三、示例（照这个语感，台词不带任何标记）

**20s 男｜液体钙｜拒绝型**

```
【时长】20 秒
【台词】
爸，我来。
不用。
二十斤呢。
二十斤咋了。
去年这袋还是我扛上来的。
去年是去年。
我爸六十三，一天一支液体钙。
两块多一支，一个月七十。
去年这两袋土，得喊我下来接。
现在他自己拎。
我说再给你买一箱，他说他自己买。
【字数】84 字
【画面】阳台搬土、抽屉拿支装、女婿提箱子进门
```

**20s 女｜骨胶原｜发现型**

```
【时长】20 秒
【台词】
妈，剪刀呢。
你那抽屉里没有。
我看看。
这什么玩意儿。
别动，我码好的。
码它干嘛。
拿着方便。
一天一条啊。
三块多吧。
一个月一百多？
一百来块，吃八个月了。
去年你拎袋米还让我下楼接你。
那我再给你买两盒。
我自己买。
【字数】83 字
【画面】翻抽屉、抓出一把条装、码回去
```
